# Dubai Real Estate Co-Broker

**Zenith Group website development · Broker onboarding and enquiry design**

[Open the live site](https://cobrokerrealestatedubai.com/) · [Evidence and verification](../../evidence/README.md)

## Business context

| Audience | Website goal |
| --- | --- |
| Real estate agencies and brokers interested in collaboration, including agents who already use the platform. | Explain collaboration and provide distinct actions for prospective partners, existing agents, and visitors browsing offers. |

## My contribution

I developed this website as part of Zenith Group’s web development program. I use this site to demonstrate how a website can separate new-partner enquiries from returning-user navigation. The partnership process is explained before visitors reach the enquiry section, while returning agents have their own portal link.

## What you can inspect

The homepage includes partnership guidance, partner and property enquiry options, and separate links for agency registration, the agent portal, and property offers.

1. [Start at the homepage](https://cobrokerrealestatedubai.com/).
2. [Find the partner enquiry section](https://cobrokerrealestatedubai.com/#enquire).
3. [Browse Dubai property offers](https://cobrokerrealestatedubai.com/dubai-property-offers/).

**Review question:** Can a new partner find the enquiry section while an existing agent can see a distinct portal link?
